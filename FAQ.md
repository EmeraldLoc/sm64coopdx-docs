# Frequently Asked Questions

## What is a ROM, and how can I get past the ROM screen

The ROM being asked for is a copy of the Super Mario 64 game. We cannot provide assistance on how to obtain this item. Do some research yourself :D

## How can I install mods

Mods downloaded can be placed either the `mods` folder in the base directory, or in `<SAVE FILE LOCATION>/mods`. You can also drag and drop mods into the window to install them.

The save file locations are:

- Windows: `%appdata%/sm64coopdx`
- Linux: `~/.local/share/sm64coopdx`
- MacOS: `~/Library/Application Support/sm64coopdx`
